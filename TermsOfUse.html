利用規約

この利用規約（以下「本規約」）は、Ryo Yoshitsugu（以下「サービス提供者」）が提供する iOS 向けの麻雀記録帳アプリ「雀ブック」（以下「アプリケーション」）の利用条件を定めるものです。アプリケーションをダウンロードまたは利用することで、利用者は本規約に同意したものとみなされます。アプリケーションを利用する前に、本規約をよくお読みください。

本規約は、利用者とサービス提供者との間の契約であり、Apple Inc.（以下「Apple」）との間の契約ではありません。アプリケーションおよびその内容については、Apple ではなくサービス提供者が単独で責任を負います。

サービス提供者は利用者に対し、利用者が所有または管理する Apple ブランドの製品上で、App Store の利用規約に定める利用規則に従ってアプリケーションを利用する、譲渡できない非独占的な権利を許諾します。ただし、同利用規則に基づき、ファミリー共有その他の方法で利用者に関連付けられたアカウントからアクセスする場合は、この限りではありません。

アプリケーションに関する著作権、商標権その他の知的財産権は、サービス提供者または正当な権利者に帰属します。

3. 禁止事項

利用者は、アプリケーションの利用にあたり、以下の行為をしてはなりません。

  • アプリケーションまたはその一部の複製、改変、翻訳、または派生物の作成
  • アプリケーションの逆コンパイル、逆アセンブル、リバースエンジニアリングその他ソースコードを抽出しようとする行為
  • 不正な手段により、購入をせずに有料機能を利用する行為
  • 法令または公序良俗に反する行為

4. 有料サービス（雀ブック Pro）

アプリケーションは、一部の機能を有料の自動更新サブスクリプション「雀ブック Pro」（以下「Pro」）として提供します。Pro の購入、課金、更新および解約は、以下の定めによるほか、Apple が定める App Store の規約に従います。

  • Pro には月額プランと年額プランがあります。各プランの料金はアプリケーション内の購入画面に表示され、購入の確認時に Apple ID に紐づく支払い方法に請求されます。
  • Pro は、現在の期間が終了する少なくとも24時間前までに自動更新をオフにしない限り、同じ期間で自動的に更新されます。更新料金は、現在の期間が終了する前の24時間以内に請求されます。
  • 自動更新は、購入後いつでも iPhone または iPad の「設定」アプリで Apple ID の「サブスクリプション」から管理およびオフにできます。アプリケーションを削除しても、サブスクリプションは解約されません。
  • 自動更新をオフにした場合でも、Pro は現在の期間が終了するまで利用できます。期間の途中での解約による日割りの返金は行いません。
  • 料金の払い戻しは、Apple の定める方法に従って Apple に申請してください。サービス提供者が直接払い戻しを行うことはできません。
  • Pro の料金やプランの内容は、変更される場合があります。料金を変更する場合は、App Store の定める手続きに従って事前に通知します。
  • 同じ Apple ID でサインインしている別の端末でも、購入画面の「購入を復元」から Pro を利用できます。
  • Pro の期間が終了した場合でも、それまでに作成した記録は引き続き閲覧および編集できます。ただし、無料プランの上限を超える新しいグループや記録帳は作成できなくなります。
  • Pro による機能の提供および無料プランの上限の解除は、Pro を購入した利用者本人にのみ適用されます。共有したグループにおいても、記録帳を作成できるかどうかは、作成する利用者本人の Pro の利用状況によって判断されます。

5. 広告および利用状況の分析

アプリケーションは、Google AdMob による広告を表示します。Pro の利用中は広告を表示しません。また、機能の改善のために、Firebase Analytics を利用してアプリケーションの利用状況を分析します。これらに関する情報の取り扱いは、プライバシーポリシーに定めるとおりです。

6. データの保存

アプリケーションで作成した記録は、利用者のデバイス内に保存され、サービス提供者のサーバーには保存されません。共有したグループの記録は、第7条に定めるとおり iCloud にも保存されます。サービス提供者は、利用者の記録のバックアップや復旧を行うことができません。アプリケーションの削除、デバイスの故障・紛失・初期化・機種変更などにより、記録が失われる場合があります。大切な記録は、利用者自身の責任でデバイスのバックアップを取るなどして保全してください。

7. iCloud によるグループの共有

アプリケーションは、Apple の iCloud を利用して、グループを他の利用者と共有する機能（以下「共有機能」）を提供します。共有機能の利用には、iCloud にサインインしていること、およびインターネット接続が必要です。共有機能の利用にあたっては、本規約のほか、Apple が定める iCloud の利用規約が適用されます。

  • 共有したグループの情報は、グループを作成した利用者（以下「オーナー」）の iCloud のストレージに保存されます。iCloud のストレージの空き容量が不足すると、同期できなくなる場合があります。
  • 招待リンクを知っている人は誰でもグループに参加できます。招待リンクの送付先は、利用者自身の責任で管理してください。
  • グループに参加した利用者は、グループ内の記録帳を閲覧、作成、編集および削除できます。グループの名前、メンバーおよび既定のルールは、オーナーのみが変更できます。
  • オーナーは、参加者を共有から外すこと、および共有をやめることができます。共有から外れた参加者のデバイスからはグループが削除されますが、それまでに保存された記録帳は、グループに属さない記録帳としてそのデバイスに残ります。
  • 利用者は、共有したグループに、他の参加者に知られることを望まない情報や、第三者の権利を侵害する情報を入力しないでください。
  • 通信状況や iCloud の状態によっては、変更が他の参加者に反映されるまでに時間がかかる場合があります。また、複数の参加者が同じ記録帳の同じ項目を同時に編集した場合、いずれか一方の変更のみが反映されます。
